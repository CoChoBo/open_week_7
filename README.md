# open_week_7

Git/GitHub 수업 시간에 실습한 내용을 정리한 저장소입니다.

## 이 저장소에서 해본 것
- 기본 파일 생성/수정/삭제
- 브랜치 생성 후 이동하면서 작업
- 브랜치 머지
- 태그 생성/삭제/푸시

## 파일 설명
- `hello.py`: 간단한 Python 실행 테스트 파일
- `files.md`: 파일 다루기 실습 메모
- `Branch.md`, `chapter-branch.md`: 브랜치 실습 메모
- `chapter-merge.md`: 머지 실습 메모
- `chapter-tags.md`: 태그 실습 메모

## 실행 방법
```bash
python hello.py
```

## 참고
- 실습용 레포라서 코드 완성도보다는 Git 명령 연습 기록에 초점을 맞췄습니다.
